# 赛博拼豆 · Bead Studio

在浏览器里拼一件**真的会翻车**的拼豆作品。

灵感来自 FORi Flower 的「赛博插花」：一张桌子、一块豆板、一盒豆子，鼠标就是你的手。
和线下店一样的流程——**选图 → 取豆 → 一颗一颗摆 → 隔纸熨烫 → 压平 → 成品**——每一步都有真实的工具、材质和可能出现的瑕疵，
所以每个人烫出来的东西都不一样。

**在线体验：<https://dittowang.github.io/pindou/>**（推送到 `main` 后由 GitHub Actions 自动构建并发布）

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 产物在 dist/，相对路径，丢到任何静态主机都能跑
npm run preview
```

需要支持 WebGL 2 的现代浏览器（Chrome / Edge / Safari / Firefox）。声音默认关闭，点「推门进去」后打开；戴耳机更好。

> 验证说明：开发期间只在 Chromium（Apple M 系列 GPU，经 ANGLE/Metal）里跑过完整流程；Safari、Firefox 和触屏真机没有实测。

## 一件作品是怎么诞生的

| 步骤 | 你在做什么 | 工具 / 材料 | 会出什么问题 |
|---|---|---|---|
| **01 选板** | 选豆子规格（迷你 2.6 mm / 标准 5 mm）、板形（方 / 圆 / 心形）、板子大小，选一张图纸，或导入自己的图片，或空着随心拼 | 透明豆板、打印图纸（色号 + 方格） | 图选得太大太碎 |
| **02 取豆** | 在豆墙前按色号点颜色，豆子整整齐齐地立进豆盘（立豆盘）的一格；可以「按图纸一次取齐」；295 色 MARD 色卡，含果冻 / 珠光 / 夜光 / 温变 / 光变 / 闪粉 | 豆勺、分格盘 | 取错色号、少取了 |
| **03 拼** | 镊子：点豆盘里的豆夹起 → 点钉子放下；豆笔：点颜色装豆 → 按住鼠标在钉子上划过，一路放豆；对图检查（红圈 = 色号不对，黄点 = 漏拼）；可撤销、可把板上的豆取下 | 尖头镊子、豆笔、立豆盘 | 拼错、看串行、漏拼——熨烫不可逆，要在这一步对图 |
| **04 熨烫** | 两种烫法：**有孔烫**——垫大理石 → 盖纸 / 布 → 粘毛 → 烫正面（按压、抬起、换位置）→ 等凉 → 揭纸脱板 → 翻面烫反面 → 书压平；**无孔烫**——先贴美纹纸、用滚筒压牢 → 倒扣脱板（豆子留在纸上）→ 盖纸烫背面，一直烫到孔洞合上 → 揭纸 → 压平 | 恒温小熨斗、烘焙纸 / 烘焙布 / 澡巾、美纹纸、粘毛器 / 滚筒、大理石板、厚书 | 烫不透、烫过头、烫到板子、晕色、孤立豆、粘纸屑、毛发被烫进去、趁热撕、翘边、高低不平；无孔烫：转印掉豆、胶残留 |
| **05 成品** | 摆桌上 / 做成钥匙扣（钻孔，可能裂）/ 装相框；看「赛博义诊」；写一句话，导出 1080×1620 的卡片 | 开口环、珠链、相框 | 钻孔裂开 |

### 真实感从哪里来

- **尺寸是真的**：世界单位 = 1 cm；2.6 mm 豆的孔径、壁厚、高低豆公差、钉子形状都按调研数值；板子 26×26 / 52×52（mini）、15×15 / 29×29（midi）。
- **熔化是模拟出来的**：每颗豆每个面有一个受热剂量 `u`，随温度指数增长（每 +15 °C 速率 ×2）、受压力、停留时间影响；豆子温度滞后于底板，大理石是散热垫。孔洞缩到一半左右最好看，再烫就糊成方块、变色、粘纸。
- **材质是程序生成的**：橡木桌面、拉丝钢、烘焙纸纤维、大理石都在 GPU 上烘焙；豆子是一个会「熔化变形」的实例化网格（圆 → 圆角方、孔收缩、厚度压缩、邻色晕染、纸屑和毛发残留、盖布压痕）。
- **特殊豆各有各的样子**：果冻通透、珠光随视角变色、夜光豆关灯会发光、温变豆升温换色、光变豆照紫外灯显色、闪粉会闪。
- **声音是合成的**：倒豆的一阵轻响、夹豆、豆子套进钉子、熨斗滑动与滋滋声、粘毛器、撕纸、桌面敲击、温控「叮」、房间底噪——全部用短脉冲和滤波噪声现场生成，没有任何音频文件；每种声音都有上限和结束，不会循环不停。
- **没有标准答案**：豆子的高低差和色差、纸上毛发的分布、你熨烫的每一次停留和力度、什么时候撕纸——同一张图纸不会烫出两件一样的作品。摆豆本身是确定的：点哪颗、放哪颗，不靠运气。

## 操作

| 操作 | 桌面 | 触屏 |
|---|---|---|
| 夹豆 / 放豆 | 点豆盘里的豆（或点画面下方的颜色条）→ 点板上的钉子；也可以按住拖过去再松开 | 同样用点按；工具尖会显示在手指上方，不挡视线 |
| 豆笔 | 点颜色装豆 → 按住鼠标在钉子上划过 | 点颜色 → 手指在钉子上划过 |
| 取下板上的豆 | 镊子点一下那颗豆 | 同左 |
| 放回豆盘 | 右键单击 / `Esc` | 点豆盘 |
| 缩放 | 滚轮 / 触控板捏合（以光标为中心）；画面下方有 ＋ − 按钮；`0` 回到全景 | 双指捏合 |
| 平移视角 | 右键拖动（摆豆时）；中键 / `Shift` + 左键拖动 | 双指拖动 |
| 旋转视角 | 右键拖动（熨烫、成品时） | 双指拖动 |
| 换工具 | 画面下方的「镊子」「豆笔」，或 `1` / `2` | 同左 |
| 撤销 | 画面下方「撤销」或 `Ctrl/⌘ + Z` | 「撤销」 |
| 给桌子腾地方 | 左上角「收起面板」 | 同左（手机上收起底部抽屉） |
| 转熨斗 | `Q` / `E` 每次转 45°（快速移动时也会自己顺着方向转） | 自动 |

画面上方的一行提示会一直告诉你下一步该做什么。

### URL 参数（调试 / 分享）

`?scale=mini|midi` 豆子规格 · `?n=26` 板子边长 · `?shape=square|circle|heart` · `?q=low|medium|high` 画质 ·
`?nowelcome=1` 跳过欢迎页 · `?seed=123` 固定随机种子（复现同一张桌子；默认每次访问都不一样）· `?debug` 显示帧率 · `?scene=patterns` 图案联系表。画质会按帧耗时自动调节。

## 开发与验证

```bash
npm run typecheck
node scripts/e2e/build.mjs      # 真实鼠标/键盘：取豆 → 夹豆 → 放豆 → 豆笔 → 撤销 → 缩放 → 平移
node scripts/e2e/iron.mjs /tmp/out holes   # 真实鼠标：粘毛 → 熨烫 → 揭纸 → 翻面 → 压平 → 成品（flat = 无孔烫）
node scripts/e2e/board.mjs      # 豆子规格、板形、自由拼、阶段往返
node scripts/e2e/mobile.mjs     # 手机尺寸 + 触摸点按
```

Playwright 不是应用的依赖：用 `PLAYWRIGHT_PATH=/path/to/playwright/index.mjs` 指向已有的安装，或 `npm i -D playwright && npx playwright install chromium`。
`PINDOU_URL=https://dittowang.github.io/pindou/` 可以让同一套测试直接跑在线上版本上（默认是本地 `npm run dev` 的 5180 端口）。

测试一律用 Playwright 的 `page.mouse` / `page.touchscreen`——它们走浏览器真实的输入管线和命中测试。
**不要**用脚本直接给画布派发事件：那样测不出「有东西盖在画布上、真实点击根本到不了画布」这类问题（这个项目就吃过这个亏）。
页面上的 `window.__dbg` 只提供**只读**的辅助（把世界坐标换算成屏幕坐标、读取状态），`window.__fill('图纸id')` 可以瞬间摆满图纸。
`scripts/shot.mjs` 是单张截图的小工具。

## 已知边界

- 没有做「毛巾 / 格利特 / 仙度瑞拉等特殊烫」和「交给店员烫」；烘焙纸 / 烘焙布 / 澡巾三种盖布和「有孔 / 无孔（美纹纸转印）」两种烫法已做。
- 色卡的 hex 来自公开整理，行业内各家实物有色差；真实豆子比屏幕色稍灰，渲染时做了降饱和处理。
- 只有中文界面。
- 摆豆的手感依赖鼠标 / 手指；触屏上较小的豆子对准钉子会比桌面难。
