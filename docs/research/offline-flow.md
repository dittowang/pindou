### 0.2 一页纸结论（给设计者）

1. **线下店的真实骨架**：选图纸 → 取板 → 在「豆墙」按色号取豆 → 坐下摆豆（镊子 / 豆笔 / 滑豆）→ 拼完交给店员（或自助烫画机）熨烫 → 压平冷却 → 穿孔/贴磁铁 → 带走。时间是收费单位（约 30–40 元/小时，或 80–100 元不限时）。
2. **国内线下店所见全是 2.6mm 小豆 + 52×52 / 78×78 / 104×104 方板**（我读到的所有店内视频转写、北青报报道都是这个规格）；5mm 大豆 + 29×29 板是国外 Perler/Hama 的传统规格，国内也有售（亲子/入门）。「国内店里 5mm 少见」这一句是我基于以上样本的推断。〔现〕〔新〕〔推〕
3. **真正的「手感」集中在三处**：摆豆时豆子「立起来→对准钉→落下」；熨烫时「看烘焙布下豆子变色/孔洞收小」；冷却时「趁热压平 + 等凉再撕」。
4. **翻车的物理本质只有几类**：热量没到位（烫不透）/ 热量过量（烫化、晕色、闷豆）/ 热量不均（高低豆、熨斗印、翘边）/ 冷却无约束（翘曲）/ 豆子位置在转移中被扰动（掉豆、移位）/ 污染物（毛、灰、布纹）/ 静电。
5. **社区文化**：翻车 → 发到评论区求「义诊」→ 有人「修复」。翻车本身是内容（「翻车大赏」「破防瞬间」）。

### 0.3 抖音转写常见错字对照（读原文时有用）

斗 = 豆；五孔 = 无孔；豆比/逗比/斗争 = 豆笔；烘背部/烘焙部 = 烘焙布；熨斗间/熨斗尖尖 = 熨斗尖；粒豆盘/绿豆盘 = 立豆盘；美文纸 = 美纹纸；格丽特/格雷特/格力特 = 格利特（glitter）；鲜度瑞拉 = 仙度瑞拉；烫发机 = 烫画机；有孔写成「油孔」。

### 1.2 分步详解（物理动作、感官、技巧、坑）

#### Step 0 进店与开台
- 店面形态：商圈写字楼里的工作室、商场里的 120 平大店（17 张桌）、手作综合店；收费按小时或按天。〔新〕
- 价格：29.4–39.9 元/小时；79.8–99 元不限时（有的含熨烫）；月卡 200 元；单次体验 1–3 小时。〔新〕
- 声音与秩序：进门有门铃；店里氛围像自习室，只有门铃声和偶尔的低声交谈；有人用便利贴记开始时间。〔新:上观、中证报〕
- 老顾客会预约；周末一桌难求；有人玩到 21 点打烊。〔新〕

#### Step 1 选图纸（对照图）
- 三种来源：店里打印好的图册（可免费现场打印，墙上/桌上有其他顾客留下的）；自带（小红书/抖音找图，手机展示或到店打印）；用图片转图纸工具自制。〔现〕〔新:济南店〕
- 图纸长相：白底方格；每格印一个色号（字母+数字，如 H7 表示一个常见黑色）；下方有「色号—所需颗数」图例；每隔若干格有红色辅助线（用来分组数格）；图边标注宽×高（如 21×31、39×44）。〔现〕
- 怎么判断用多大的板：先看最外圈的格数；21×31、39×44 这类用 52 小板就够。〔现〕
- 对照方式：手机/平板立在桌上的支架（店里放的支架只稳得住 52 小板）；或打印稿放板旁；也有「透明板垫在打印稿上描着摆」的做法（缺点：深色豆叠在图上看着脏）。〔现〕〔二〕
- 新手建议：轮廓清晰、色块分明、少渐变；线条简洁的图容错率高。〔二〕〔新:澎湃〕
- 镜像：是否镜像取决于烫法（见 Step 8）。图纸上有文字时必须想清楚最终朝向。〔现〕〔二〕〔英:Hama 视频提醒文字要反着放〕

#### Step 2 取板与清板
- 板子：白色塑料方板，表面是规则凸钉；店里常见 52×52 小板、78×78 中板、104×104 大板；异形板有圆形、爱心、星形、六边形。推荐「长钉」「带格线」版：长钉让豆子站得稳，格线便于数格；透明板被不少博主劝退（不耐烫、钉矮）。〔现〕
- 取到后用小刷子刷掉灰尘浮毛（店里的标准动作）。〔现〕
- 板子反光会让眼睛疲劳；有人自己喷哑光漆；北青报里有大学生说拼豆有点伤眼，另有电视台视频提到医生建议单次拼豆时间不要太长（视频标题给出 20 分钟，仅标题，未读到正文）。〔现〕〔新:北青报〕
- 板子放在托盘里，端着托盘走，别单拿板子（半成品极易碰散）。〔二〕〔推〕

#### Step 3 取豆（豆墙）
- 豆墙：靠墙的柜子，五颜六色的小方盒/瓶，按 A–M 系列分类，盒/瓶身贴色号标签（A1、B2……）；客人拿篮子/餐盘，对着图例一个色号一个色号拿，方式像在麻辣烫自选台挑菜。〔新:上观〕〔现〕
- 单位：店里一瓶/盒大约一千多颗；一种颜色拿一瓶通常够。〔现〕
- 开盒方式：轻捏瓶盖两侧即开；开盖前先摇匀、放平再开，防止撒出来；倒回时让盖子斜着，把盖里的豆子倒回瓶。〔现〕
- 付费方式：多数店按时间计费；也有品牌店把「多巴胺豆墙」做成自助称重，按重量买单。〔新:人人都是产品经理〕
- 有的店在主豆墙外还有一面「补色墙」，颜色不够时去补。〔现〕
- 取完后：用不上的颜色还回去，才能继续拿下一幅的色号。〔现〕
- 相近色：W 白/奶白、黑/深灰、天蓝/湖蓝这类，在盒子里看不出差别，放到画面上才暴露；有 SEO 教程建议备豆时把相近色摆在托盘两端。〔二〕

#### Step 4 就座与布置
- 桌面：手机支架 + 台灯（店里常配），工具包里常见：小漏斗、三角盘/立豆盘、豆铲、直镊+弯镊、单针+双针。〔现〕
- 姿势：低头弯腰，长时间会腰酸背痛、颈椎不适；眼睛疲劳；手腕要搭在桌面上，否则手抖。〔新〕〔现〕
- 〔二〕建议的布局：从左到右「图纸 → 板 → 备豆碟」，视线移动最短；板下垫浅色托盘（深色豆掉在深色桌上很难找）。

#### Step 5 摆豆（pick-and-place）——这是整件事的「手感核心」

**三种手法**

| 手法 | 物理动作 | 适用 | 速度 | 对豆子的要求 |
|---|---|---|---|---|
| ① 镊子 + 立豆盘 | 倒一小撮豆进立豆盘，轻轻摇晃，豆子立起来（孔朝上）；尖头镊子夹起 1–2 颗；垂直对准豆钉按下；松开 | 零散色、收边、改错 | 慢（约 12–18 颗/分，〔二〕） | 无特殊 |
| ② 豆铲 + 豆针/豆笔「点放」 | 豆倒在豆铲上，晃动让豆立起；针尖对准豆孔把豆「串」起来（一次一颗或一小串）；捏笔身发力点控制松紧——捏紧夹住不掉、放松落下；节奏「松 → 提 → 夹」 | 快速铺色 | 中 | 孔径一致、无毛刺 |
| ③ 滑豆 | 双针串一串豆（60/70/80 颗）；第一颗稳稳落在钉上后松开，针尖略抬到「刚比一颗豆高一点」，水平平移，后一颗从前一颗上「滚/滑」下来落到下一个钉；手要跟着笔往下走，否则像「圆规」 | 大面积同色、直线 | 最快 | 无毛刺、无高低豆；板必须长钉 |

**手上的细节（来自多位店员/博主）**
- 把针「对着自己」，方便看落点；豆子一定要放在钉上而不是钉间缝里；大拇指放在笔身的凹凸位，像握笔一样控制松紧。〔现:店内教程〕
- 单针要先用豆铲「咬」好豆；对着钉子松手、往上提一点点，再用笔上的夹口夹住下一颗。〔现〕
- 手腕放桌上；笔尽量垂直于板；斜着进针容易把周围的豆撞倒或把豆「横过来」。〔现〕
- 四周都有豆的空位：先把两根针尖同时伸进缺口，对齐再松手，再提起；缺口太窄就挤开旁边一颗。〔现〕
- 镊子的一种说法（含义略含糊，单一来源）：夹豆时镊子的一边尖要伸进豆孔里，另一边对着钉子；博主还提醒要有耐心，手需要慢慢练熟。〔现〕
- 豆笔手感可以调：把针掰正；用皮筋夹在笔上控制夹力——皮筋越往下夹力越小（适合一颗颗放），越往上越松（适合滑豆）。〔现〕

**顺序策略**
- 店里老手的常见顺序：先勾外轮廓（一个深色号，如 H7）→ 先拼小色块 → 最后大面积填色；从最上面一行开始，免得拼到一半板不够。〔现〕
- 颜色碎、轮廓断续的图，按行从左到右更稳；把连续同色读成「空 3、黑 2、白 5」这样的小段。〔二〕
- 每 5 行/5×5 停一下：先数格，再看锚点是否对齐，最后退远看轮廓。〔二〕

**感官**
- 声音：无声直播间里只有哒哒的声响；用好豆子时下豆声音清脆；滑豆连发被形容为机关枪般的落豆音效；豆子倒进盒子/掉落时的「哗啦」声被做成 ASMR；店里则几乎是静的。〔新:今日头条〕〔现〕
- 触感：豆子轻、小、容易带静电（见翻车图鉴）；新开袋/干燥天最严重；豆铲里倒豆时豆子可能崩飞出来。〔现〕
- 节奏：一颗一颗进入「放空」，旁边人几乎不说话；有人带电脑边拼边工作，甚至开着会拼。〔新:虎嗅〕

**时间**：新手一小时内能拼出手掌大小的作品；含选图到出炉的全流程，B 站一位博主第一次进店「小图」约 2 小时；用色多的偶像小人约 40 分钟；一位大学生 vlog 里一件作品共用时 10 小时 12 分钟；104×104 满板大图 13 小时；有人单次待 7–8 小时、一次出 5 件。〔新:中证报、上观〕〔现〕

#### Step 6 核对与改错
- 熨烫不可逆，所以先核对：站远看整体；对照图纸一行行数；手机垂直拍照与原图并排对比。〔二〕
- 单颗错：尖头镊子垂直夹起再放（避免带倒周围）；整块偏移一格：未熨前整体挪格（十几分钟能修好）。〔二〕
- 事实上店里最常见的是「拼错而耽误时间」。〔现:大学生 vlog〕
- 如果已经贴了美纹纸才发现拼错：用两把平底豆铲压住，缓慢平移并垂直下压，一点点把纸「撤回」；不要硬撕。〔现〕
- 如果已经拼完但忘记镜像：另取一块（最好透明的）板，豆钉朝下盖在拼好的图案上；钉子卡进每颗豆孔时会「咔嗒」一声，说明卡好；小心整体翻转，揭开原板即可。英文博主把同一招叫 tortilla flip，用来把偏出板外的小图重新居中，或让图案左右翻转。〔现〕〔英:RQ9mCd9kW9o〕

#### Step 7 交烫 / 备烫
- 店内：把板子端到前台/烫豆台，告诉店员要哪种烫法；店内提示牌写着每种特殊烫的注意事项；烫好的成品在取件区取。〔现〕
- 店内特殊烫（我读到的两家店都免费；别的店可能加价）：彩虹粗闪、黑色粗闪、偏光细闪、粉粗闪、银色粗闪、毛巾烫、澡巾烫、单面无孔。〔现〕
- 搬运的紧张感：店员形容端着一块 13 小时的大图走几米像走了一辈子，一路提醒自己再慢一点；一旦撞翻就是全部白做。〔现〕
- 谁来烫：多数店由店员烫（济南店：没经验的不建议自己烫，容易烫伤或烫坏）；也有店提供自动烫画机/自助熨烫机；中证报报道里有店员一边给排队的顾客热压作品。〔新〕
- 设备：先用熨斗，后来加购 200 元的小烫画机、2000 多元的专业烫画机，以应对高峰。〔新:中证报〕
- 烫制时长：小图几分钟；济南店说用低温挡均匀熨烫三四分钟；104×104 大图店员边挪位置边看，烫了半个多小时。〔新〕〔现〕

#### Step 8 转移：美纹纸法（「无孔烫」的前置步骤）
这是国内最普及的做法。动作链如下（多位博主一致）：
1. 板子微微倾斜 30–45°，用手指或豆针在板背面轻轻敲，让豆子在水平方向对齐；转 90° 再敲一次对齐垂直方向。要「轻」——敲重了豆子会跳。〔现〕
2. 选 ≥5cm 宽的美纹纸（窄的便宜但接缝多；透明胶带太黏，被吐槽「大翻车」）；目测够长；有博主建议离板边约 1.5cm 处对齐，默数 3-2-1，两手同时落下按压，一次贴准，不能犹豫。〔现〕〔B站:BV1h99CBCEaR〕
3. 用豆铲、胶带卷或手掌滚压，边缘多压；每条纸重叠上一条边缘一点点，保证每颗豆都沾到纸。〔现〕〔英〕
4. 纸的多余边折起（不让胶沾到烘焙布）。〔现〕
5. 一只手压住纸，把板子倒扣，用手或豆铲敲板背，让豆子脱离钉子；像「翻书」一样从一侧掀开板子；若有掉豆立刻补。〔现〕〔英〕
6. 注意：图纸要先镜像。规则（一位店主总结）：用美纹纸做单面无孔 → 要镜像；直接在板上烫 → 不用镜像；毛巾/澡巾/格利特/仙度瑞拉这类特殊烫，用美纹纸 → 不用镜像，不用美纹纸 → 要镜像。〔现〕

#### Step 9 熨烫（熨斗/烫画机）
**9.1 烘焙布与垫板**
- 烘焙布：白色特氟龙涂层的玻璃纤维布，0.11 / 0.18 / 0.25 / 0.45 mm 几种厚度，粗纹/细纹；新手多推荐 0.25mm 粗纹（更厚更耐高温、不易搓泥、不易绒边）；用贴纸标出「接触熨斗的一面」，另一面接触豆子，不要调换；用久了表面涂层起毛，寿命约 10–20 次。〔现〕〔二〕
- 清洁：先用毛刷/滚刷刷豆子表面，再用粘毛器粘烘焙布接触豆子的一面；也有人用美纹纸粘满后用手按压摩擦（会缩短布的寿命）。〔现〕
- 垫板：大理石板、岩板、瓷砖、玻璃都可以，作用是散热、避免「闷豆」；家里没有就在瓷砖地上烫，或垫一块打湿的洗脸巾；有博主去瓷砖店买了一块约 32×60cm、几块钱的瓷砖（专用散热板几十元却还没一张小号烘焙布大），从此不再趴在地上烫；热了就换个凉的位置，因为底部过热会把有孔面烫化。〔现〕
- 防熔边：图案周围用废豆/混豆围一圈，与主体至少隔两个钉。〔现〕〔新:果壳〕
**9.2 熨斗**
- 小熨斗（20 元左右「大白熨斗」，或小粉熨斗、AFC 等）；常设最大档；预热时听到「叮」/「咔嘣」/「滴」就是到温；恒温指示灯亮一会儿熄灭，说明在循环加热，有人把「灯灭 → 换位置」当计时器。〔现〕
- 同一台熨斗的温度分布：多位博主说「尖/前半部分更烫」，用熨斗尖去补小孔；也有二手教程说中心最热、尖头较凉——二者矛盾，应视具体机型而定。〔现〕〔二〕
**9.3 动作（单面无孔，博主共识）**
1. 先「按压 → 抬起 → 移动 → 再按」，不要一上来就横向拖（会让线条歪）；每个点停留约 3–6 秒；换位置也要换朝向（防止背面豆被烫化）。〔现〕
2. 用熨斗自重，别使劲压（新手用力会「晕色」）；熟练后在大图上可以适当加力。〔现〕
3. 观察：隔着烘焙布看豆子——颜色变深，圆圈变成方形，说明已粘到布上；拿起布从侧面看更清楚。约 40–60 秒后翻回来。二手教程还建议每隔一会儿轻轻掀起烫纸一角看融合情况；英文博主强调每颗豆都至少熔了一点之前不要抬熨斗。〔现〕〔二〕〔英〕
4. 撕掉美纹纸：不要等太晚，否则空气排不出，容易闷豆；也不要太早，撕早了没粘牢的豆会被一起撕走。〔现〕
5. 继续熨：慢速平移或点按，直到每颗豆连成一片；边缘要补。〔现〕
6. 圈 vs 平移：官方与英文博主以画圈为主；国内无孔博主分两派——一派主张平移或点按（线条更直，画圈会把边缘线烫歪、晕色），另一派主张打三圈就换位置、遵守五秒原则。〔官〕〔英〕〔现〕
**9.4 烫画机（店里的主力）**
- 设置：145–150℃，10–20 秒起步，不够就垂直按压；大图分区压，每轮换朝向；到温「滴」一声，计时结束再「滴」。〔现〕
- 澡巾烫示例：烘焙布粗烫转移后，换澡巾；160℃×60–70 秒；两台机器并行，接缝处加压。〔现〕

#### Step 10 对光检查与补烫
- 翻到背面，对着台灯/窗光/手电筒看：透光的小点就是没烫透的孔；烫一烫、照一照，循环。〔现〕
- 补孔：用熨斗尖在孔处点按约 3 秒，再整体过一遍；注意同时照顾周围，否则这一块会过薄导致整体不平。〔现〕
- 「留一截」技巧：撕烘焙布时不全撕下，留一段，这样可以直观看到哪里有孔，直接盖回去复烫，也避免粗纹布错位压乱纹路。〔现〕
- 官方/英文标准是透过纸看到颜色变清晰、中间孔洞收小；国内无孔追求是孔完全看不见。〔官〕〔英〕〔现〕

#### Step 11 降温、撕布与脱板
- 等不烫手再撕，因为热的豆是软的，趁热撕会拉变形；加速降温：扇风、湿巾擦布面 20–30 秒、铁块/降温板压 5–10 秒。烘焙布「微微鼓起」可以撕。〔现〕
- 例外：毛巾烫要趁热撕，凉了粘死撕不下来；先撕烘焙布，再撕毛巾。〔现〕〔二〕
- 感官：有博主说撕澡巾的声音特别解压，甚至想要一份专门撕澡巾的工作；撕拼豆有「沙沙」的 ASMR。〔现〕〔B站 ASMR 标题〕
- 英文教程：撕纸时手压住胶带、一把拉走才不会留下折痕（带胶带的做法）。〔英〕

#### Step 12 压平
- 刚离开熨斗那一刻作品是平的，几十秒后才开始弯——所以要立刻压。厚书、瓷砖、重物都行；压板要比作品大；整体烫完再一次性压；压到完全冷透；长条作品沿长边压直尺。〔二〕〔现〕〔英〕
- 用「大理石/瓷砖 + 书」组合是常见做法。〔现〕

#### Step 13 翻面（第二面）
- 单面无孔的反面保留板钉凹出来的「有孔面」；想要双面：翻面盖布，再烫一遍，时间更短（豆已预热）。〔现〕〔英〕〔二〕
- 官方建议双面都烫；英文博主说有人只烫正面、另一面保留孔洞，自己则偏爱两面都轻烫。〔官〕〔英〕

#### Step 14 后处理
- 挂件/钥匙扣：摆豆时就预留一颗空位当穿孔，往内缩一格；或用镊子尖在顶部两点向中间挤压戳孔；开口环（8mm 规格）+ 老虎钳压紧 + 链条/挂绳；店里的「成品穿孔区」提供 3mm、6mm 的开口环/珠链。〔现〕〔二〕
- 冰箱贴：背面贴片状磁铁，强力双面胶或热熔胶，位置靠近重心；背面要先熨平。〔二〕〔推〕
- 其他形态：包挂、车挂、扇子、发夹、轴承（旋转）、洞洞鞋花、挪车牌、杯垫、相框、星星人灯（透明豆+磁吸发光装置）。背胶可把成品固定到手机壳；装框要匹配画框内径与深度。〔现〕〔新〕〔二〕
- 毛刺：成品边缘的毛边可用指甲轻刮；围一圈废豆本身就是预防。〔二〕〔现〕

#### Step 15 离店
- 用过的豆归位；拍照；很多人会把成品与图纸一起拍照晒到社交平台。〔新〕〔现〕

### 1.3 居家 DIY 与线下店的差异，以及一个样例时间线

- **起步花销**：一位博主给出的最省方案——120 色补充装、一支豆笔、豆铲、52×52 白色长钉板、0.5mm 粗纹烘焙布（一米约 9 元，自己裁剪包边）、20 元左右的大白熨斗、5cm 以上宽的美纹纸，合计二百出头。〔现〕
- **重度玩家的账单**（虎嗅采访的玩家）：221 色全系列豆 280 元、收纳袋 20、大号收纳盒 32、魔术贴 20、毛毡板 80、豆针/豆盒/镊子 30、大中小豆板 50、美纹纸 20、烘焙布 20、格利特闪布 20–30、烫画机 299 元；还买了二手 iPad 看图、换了人体工学椅、追加了 5000 颗豆；豆子和闪布是持续消耗品。〔新:虎嗅〕
- **在家的痛点**：需要操作空间；没有专业烫豆设备；补豆要等物流。〔新:虎嗅〕
- **分装**：整袋豆分进 30ml 小药瓶（一个约 0.2 元，一瓶约 12 克）+ 大号文件收纳盒（一盒 60 瓶）；色号贴贴瓶身而不是瓶盖；没有漏斗就卷纸成筒；一位博主分装 221 色自称花了大半天（另一条 B 站视频标题写 144 色分装耗时四小时）。〔现〕〔B站〕

### 1.4 老手口诀汇总（散见于店员与博主视频）
1. **摆**：先勾外轮廓，再小色块，最后大面积铺色；从最上面一行开始；针垂直、手腕搭桌。〔现〕
2. **备**：板和豆面先刷；烘焙布先粘毛、贴标记贴；垫大理石/瓷砖/岩板。〔现〕
3. **围**：图案外围用废豆围一圈，与主体至少隔两个钉。〔现〕
4. **转**：美纹纸 ≥5cm，3-2-1 快准狠；滚压；折边；倒扣；先镜像。〔现〕
5. **烫**：先轻按、抬起再移；每点 3–6 秒；勤换位置与朝向；用自重、不使劲；孔用熨斗尖点补。〔现〕
6. **看**：烫一烫看一看，翻面对光；侧面看高度；颜色变深、圆变方。〔现〕
7. **撕**：美纹纸别撕太晚也别太早；布等不烫手再撕（毛巾烫趁热）；留一截确认。〔现〕
8. **压**：立刻压到彻底冷；压板比作品大；尽量双面。〔二〕〔英〕〔现〕
9. **试**：拿废豆摆 5×5 小片校准自己的熨斗（二手教程建议 8/12/16 秒三档），换豆径/品牌/熨斗要重测。〔二〕
10. **修**：别扔烫坏的；复烫、澡巾、格利特、热风；去评论区「义诊」。〔现〕〔新〕

### 2.3 豆子在「手」里的物理（为模拟准备）
- **会自己立起来**：豆倒在有挡边的豆铲/立豆盘里晃动，会自然朝「孔朝上」站起来，这是用针串豆的前提。〔现〕
- **有静电**：新开袋、冬季干燥、运输摩擦后最严重；表现为粘在针上下不来、粘在袋子/铲子上、倒进铲子会飞崩、豆与豆相吸、没切断的连体豆。〔现〕
- **毛刺/高低豆**：会让滑豆不顺、熨烫后线条不直、表面不平。〔现〕
- **靠钉子定位**：长钉让豆站得更稳（滑豆时第一颗必须稳稳立住）；板被烫弯变形后，豆子轻轻一碰就飞起来。〔现〕
- **颜色会变**：黑色豆在烘焙布下颜色变深是粘合的信号；白豆烫后偏黄（EVA 氧化）；浅色烫后饱和度下降。〔现〕〔新:果壳〕〔二〕
- **熔合时收缩**：高度压到原来的约 1/3–1/2 就算熔合；继续烫孔会闭合；过头则整体软化流动。〔现〕〔二〕

## 3. 翻车图鉴（「翻车」= 失败；圈里还叫「烫毁」「报废」「烫到火葬场」）

> **频率说明**：没有任何来源给出可靠的统计数字。下面的 ★ 是我根据「有多少教程/修复视频专门讲它」「媒体和博主是否称其为最常见」做的定性估计：★★★ 极常见（几乎每个人都会遇到）/ ★★ 常见 / ★ 偶发 / ☆ 罕见但后果严重。均标〔推〕。
> 某位抖音博主的一句自嘲很能概括这件事：拼豆一时爽，烫到火葬场。

### A. 摆豆阶段

**A1 拼错 / 看串行 / 整块偏移一格** ★★★
- 外观：图案与图纸对不上；有时不是一颗，而是一整片/整行整体错位。
- 成因：把相邻行看成另一行；数长距离空格数乱；中途换坐标。〔二〕
- 现场：店里的大学生 vlog 提到拼错很容易发生，耽误了不少时间。〔现〕
- 预防：用直尺压住当前行；打印稿拼完一行划一行；每 5×5/5 行停下数格；退远看。〔二〕
- 补救：未熨前整块挪一格十几分钟可修好；已烫的几乎只能「拼回去」——有博主演示把烫坏的区域按块重新拼回去并补熨。〔二〕〔现〕

**A2 相近色混淆（白/奶白、黑/深灰/碳黑、天蓝/湖蓝……）** ★★
- 外观：盒里差别不大，铺成一片后「那一块颜色不对」。2.6mm 小豆深色系尤其难分。
- 成因：灯光与屏幕色差；盒中近似色相邻；熨烫后浅色会变（纯白→更接近奶白），原本不同的两色变得更接近。
- 预防：备豆时把相近色分开放、一次只放一种；用日光灯；重要色先做小样。（店里要求用完的颜色还回豆墙，我推断也有防混色的作用。）〔二〕〔推〕
- 补救：未熨前逐颗替换，费时但可行。〔二〕
- 备注：我没找到第一手的「配色号时搞混」的详细叙述，此条主要依据二手教程，证据偏弱。

**A3 漏拼 / 空位 / 孤立豆** ★★
- 外观：图案中有空缺；周围全空的孤立豆。
- 成因：漏看；图纸中本身存在单格点缀。
- 后果：孤立豆熨烫后基本一定会掉；一两格宽的细结构（月牙尖、字母笔画）最易断。〔二〕
- 预防：熨烫前站远整体看；设计时把一格宽的结构加粗；熨时当作边缘多停几秒。〔二〕

**A4 豆没到底 / 横躺 / 歪斜 / 摆在钉间缝里** ★★
- 外观：豆子没套进钉、斜着或横着躺；有人把豆摆在钉与钉之间的缝里，被圈内当作迷惑行为（B 站有条视频标题就在调侃这种做法，意思是豆子本该摆在钉上）。
- 成因：针/镊不垂直；四周都有豆、间距小时硬塞会把豆「横过来」；豆间留缝会导致熨后连接不牢。〔现〕〔二〕〔B站〕
- 预防：针垂直板面；缺口过窄先挤开旁边一颗；板子倾斜 30–45° 轻敲背面让豆子靠齐，转 90° 再敲一次。〔现〕
- 声音线索：重新翻转用的第二块板，钉子卡进每颗豆孔时会「咔嗒」一声，表示卡好。〔现〕

**A5 静电：豆乱跳、粘针、粘袋、飞崩、连体豆** ★★★（冬季/新开袋）
- 外观：豆粘在豆针上抖不下去；倒进豆铲还会飞崩出来；豆与豆互相吸、一颗黏一颗；袋子里的豆倒不出来。一位博主形容自己光顾着捡飞出来的豆。
- 成因：塑料间摩擦；运输中豆子在空瓶里反复摩擦（30ml 小方瓶装 12 克左右时空隙大）；空气干燥（有二手来源称湿度低于约 40% 更明显〔二〕）；金属/塑料针端也带电；高透豆更明显。〔现〕
- 预防/补救（多位博主）：棉签蘸水（或酒精）搅进袋/瓶后用力摇；细雾喷壶加少量护发素，隔约 30cm 喷 1–2 下并晾干；对着袋子哈气摇晃；桌面放迷你加湿器；用陶瓷针；倒豆动作放慢、少开合盖。〔现〕
- 副作用：太湿豆子会粘住针和瓶壁，要晾干。〔现〕

**A6 毛刺 / 高低豆 / 连体豆 / 孔径不一** ★★
- 外观：豆侧面有毛边；同色豆高度不一；个别没切断的两颗连在一起。
- 成因：切粒工艺；批次质量差异。实测一个品牌：高度最大差约 0.146mm，直径差约 0.102mm。〔现〕
- 后果：滑豆滑不动、卡针；熨后表面不平。
- 预防：买融合豆、挑「无毛刺、无高低豆」的品牌；这是新手教程第一条建议。〔现〕

**A7 被撞飞 / 打翻 / 一整板倒掉（毛衣勾板、抬手打翻）** ★
- 现场：上海一家店里有人聊得兴起一抬手打翻了豆板，豆撒了一地（那是拼了一阵的半成品，当事人情绪倒很稳定）；北京一家店里 21 岁玩家因毛衣勾到板子，作品当场散架，要花数小时重做；动作幅度大会把拼好的豆撞飞；店员端 13 小时的大图去烫台，紧张到手抖。河南都市频道视频标题：一个人弄撒了会崩溃，两个人一起弄撒反而成了共同的笑点。抖音「拼了一天的豆洒了」视频获 9.1 万赞。〔新〕〔现〕
- 成因：未熨的豆只靠钉子摩擦固定，极脆弱；袖口、桌面晃动、碰撞。
- 预防：板子放托盘整盘端；中途收工用硬板/保鲜膜轻覆；桌子要稳；搬运端平慢走。〔二〕〔现〕
- 补救：几乎无法部分补救，只能对照图纸重摆。〔二〕
- 气流（风扇/空调/喷嚏/呼气）：我没找到直接来源。〔推〕2.6mm 豆约 0.01 克（12 克≈一千多颗），理论上很轻，易被气流扰动。
- 猫：果壳转述了小红书上的玩笑——最崩溃的翻车据说是让猫进了摆豆的房间。〔新〕

**A8 毛发 / 灰尘 / 纤维 / 宠物毛** ★★
- 外观：成品里看到一根毛、黑点、绒絮。
- 成因：豆面或烘焙布上有浮毛；毛巾烫的旧毛巾没洗净；撕布时空气中的毛被带电的热塑料吸附。〔现〕
- 预防：板子先刷；熨前用毛刷扫豆面，吹一下；用粘毛器粘布的豆面；烘焙布上下都粘；压放凉后再揭，减少空中毛吸附。〔现〕
- 补救：毛巾烫粘毛可热水泡 + 用力刷洗（B 站视频）；局部可复烫。〔B站〕

### B. 转移阶段（美纹纸 / 倒扣）

**B1 粘不牢、翻转时散、掉豆** ★★
- 成因：胶带没压实/粘性弱；犹豫（越犹豫越容易散）；边缘没压；大图一次翻太慢。〔二〕〔现〕
- 预防：「快准狠」一次贴准；滚压边缘；翻转时用两块硬板夹住（BeadsCanvas 与英文博主 Beadamonpixels 都有这个建议）；窄美纹纸一层层贴有个好处：出错时补救成功率更高。〔现〕〔英〕〔二〕
- 补救：掉的豆补回；掉在大图接缝处的豆用美纹纸重新穿回。〔现〕

**B2 贴上美纹纸才发现拼错** ★
- 补救：两把平底豆铲压住，缓慢平移并垂直下压，把纸「撤回」。〔现〕

**B3 忘记镜像 / 反字** ★★
- 外观：烫出来的字或图左右反了（含文字图案最致命）。
- 预防：先决定烫法；用美纹纸做单面无孔必须镜像。〔现〕
- 补救：用第二块透明板整体翻转（见 Step 6）。〔现〕

**B4 透明胶带太黏、胶残留** ★
- 外观：豆被胶带粘死撕不下，胶残留在豆或烘焙布上。〔B站〕〔英〕
- 预防：用美纹纸；折起纸边；英文教程说胶残留可用洗洁精擦。〔英〕

**B5 （英文教程）胶带没戳孔 → 鼓泡/炸豆** ★
- 英文博主强调：用胶带法时要在每颗豆上戳孔让热和空气出去，否则容易鼓泡、豆「爆」。中文无孔法的对应做法是「熨到一半就撕掉美纹纸排气」。〔英〕〔现〕

### C. 熨烫阶段

**C1 烫不透 / 烫不实（没烫到位）** ★★★
- 外观：中间孔仍透光；撕布时一些豆没粘上；取下来一捏就散、拿起来豆「噼里啪啦」掉；边缘豆先掉。
- 成因：温度低于软化点（时间再长也没用）；时间短；熨斗在中间画圈，边缘只被扫过一两次；烘焙布起皱处受热不足；对着熨斗蒸汽孔的位置偏凉。〔新:果壳〕〔官〕〔二〕
- 英文博主补充：熨斗太早抬起时，已熔的一块会翘起/粘在纸上，剩下没熔的豆被拍散，基本救不回来。〔英〕
- 预防：官方建议——边缘不融合就升温；沿轮廓再走一圈，每边停 2–3 秒；多次对光检查。〔官〕〔二〕
- 补救：局部点按补熨 5–8 秒；粘在纸上的豆揭下放回原位再烫（官方做法）。〔官〕〔二〕

**C2 烫过头 / 烫化 / 糊（「烫到火葬场」）** ★★★
- 外观：孔全没、表面发亮像一整片塑料；每颗豆融成圆滚滚一坨，色块界限模糊；脆、发黄、缩小、卷边。
- 成因：温度高或停留久；有品牌豆熔点低（高透豆）；同一点反复压。
- 性质：不可逆，一旦所有孔洞消失就失去颗粒质感。〔二〕〔新:果壳〕
- 预防：先在边角或废豆做试片；单次点按 6–10 秒并频繁观察；官方：中间孔开始闭合就降温。〔官〕〔二〕
- 补救：作为「校准样本」，下次减 3–5 秒或降一档。〔二〕

**C3 闷豆（小坑、不透光的浅凹点）** ★★★（追求无孔者几乎都遇到）
- 外观：小孔不透光、表面像一小块塑料，比周围略凹；有时是背面有小气泡。〔二〕
- 成因（多位博主）：垫板导热差或积热，底部把有孔面的豆烫化；同一点停留过久；美纹纸撕得太晚空气排不出；不换位置/朝向。〔现〕
- 预防：垫大理石/瓷砖；勤换位置和朝向；撕美纹纸别拖；用粗纹烘焙布。〔现〕
- 补救：局部复烫（背面轻刮式点按）；单色区可「打补丁」——同色豆烫成薄片、剪成一颗豆大小盖上再烫；整图可用加厚澡巾 170℃×30 秒×多轮复烫，每轮转向。〔现〕〔二〕

**C4 晕色 / 色块边缘弯曲** ★★
- 外观：色块边缘不整齐、颜色互相洇开；线条歪。
- 成因：软化期豆子被推动：用力+大幅打圈会让边缘线错位混合；一开始就横向拖也会让线条歪。
- 预防：先点按再移动；垂直向下均匀小幅移动；新手别使劲压。〔现〕〔二〕
- 反例：官方/英文博主教的是画圈——可能因为他们熨的是有孔半融状态，豆子仍被钉固定。〔推〕

**C5 熔边 / 炸边 / 绒边 / 毛边** ★★
- 外观：图案外圈的豆被压得过熔，外溢成毛糙的薄边。
- 成因：边缘被施加过多压力；边缘无支撑、散热快却被反复熨。
- 预防：图案周围用废豆围一圈，与主体至少隔两个钉，宁可熔掉这一圈；粗纹烘焙布更不易绒边；特殊烫有「直角围边防炸边」的专门教程（B 站）。〔现〕〔新:果壳〕〔B站〕
- 补救：成品边缘毛刺用指甲刮平。〔二〕

**C6 高低豆 / 表面凹凸 / 波浪 / 孔洞大小不一** ★★
- 外观：同一色块表面起伏；孔洞有大有小。
- 成因：豆子高度公差；受热不均；纸起皱；对着蒸汽孔；板变形导致豆处于不同高度；同一色块混用不同品牌（熔点不同）。〔现〕〔二〕〔英〕
- 英文博主展示：一块略弯的板，让较高的豆先熔、较低的不熔，成品有一道波浪线。〔英〕
- 预防：同色块同品牌；板要平；用美纹纸法脱离板子；换平整的烘焙布。

**C7 烘焙布粘豆 / 拉丝 / 撕不下来** ★★
- 成因：太热时撕；温度过高豆焊在布或钉上。〔官〕〔二〕
- 官方：别太快揭纸，粘在纸上的豆放回去再烫。〔官〕
- 预防/补救：等冷却，从角上水平慢慢揭，不要垂直上拉。〔二〕

**C8 纸/布的痕迹：褶皱压痕、布纹错位、搓泥、白点、起毛** ★★
- 外观：成品上有一条折线；布纹被烫乱；烘焙布表面起毛、豆上出现白点。
- 成因：烘焙纸有折痕会压出一条线（英文教程还建议折痕尽量落在图案的暗线/脖子/地平线等天然分界上）；粗纹布揭下再放回时纹路一旦错位，会被烫乱；布老化（10–20 次后）；脏布印到豆上（PixelBeads 所谓「要换布」）。〔英〕〔现〕〔B站〕〔二〕
- 预防：不用折过的纸；每次同一面朝豆；撕布时「留一截」；换新布。〔英〕〔现〕

**C9 熨斗印 / 烫斑 / 局部过熔** ★★
- 外观：成品上出现熨斗底板的形状/一块发亮的区域/蒸汽孔印。
- 成因：底板冷热不均；停留过久；蒸汽孔处偏凉另一处偏热；大熨斗的蒸汽孔印；起皱的纸造成不同受热面。〔二〕〔现〕
- 预防：勤换位置，先贴合再轻轻上下左右滑动让整体温度一致；用无蒸汽孔的熨斗。〔现〕〔二〕

**C10 烫到板子 / 板被烫弯 / 烫化 / 豆焊在板上** ★
- 外观：板面起波浪、钉被软化；豆焊在钉上取不下；被烫弯的板一碰豆子就飞起来（博主求助帖的描述）。
- 成因：直接在板上长时间/高温熨；用力压；熨斗扫到板子的非图案区。〔官〕〔英〕〔现〕
- 预防：图案以外别熨；大图用美纹纸法让豆离板；英文博主 BigBossRazz 提醒：压太重会把板熔弯。
- 补救：已变形的板很难恢复。〔二〕

**C11 熨烫中掉豆 / 豆被烘焙布带走** ★★
- 补救：把掉的豆放回原位补熨；或有人把烫坏的区域「拼回去」。〔官〕〔现〕

**C12 烘焙布忘区分正反 → 白豆被烫脏** ★
- 外观：白色豆上有灰色布印（一位博主的白脸 Kitty）。〔现〕
- 预防：给布贴标记贴，永远同一面朝熨斗。

**C13 特殊烫失败（格利特 / 澡巾 / 毛巾 / 仙度瑞拉）** ★★
- 格利特：闪片移位、表面凹凸、豆子溢边、闪亮质感一烫就消失；温度窗口很窄（太低闪片粘不上，太高布撕破）；通风要好。〔二〕〔现〕
- 毛巾烫：第一次温度没控好，图案糊了；毛巾太新/太软、没洗净；撕晚了粘死。〔二〕〔现〕
- 补救：坏豆/烂豆可以用格利特布垫毛巾「复烫」（一位博主说 30 秒拯救一切坏豆）；加厚澡巾复烫；闷豆/特殊烫失败都可以用这招。〔现〕

### D. 冷却与成品

**D1 翘边 / 翘曲 / 拱起 / 弯曲（「做卷腹」）** ★★★
- 外观：刚烫完平的，放凉后边缘上翘、整体拱起、长条沿长边弯。
- 成因：塑料受热膨胀、冷却时不均匀收缩；受热多的一面收缩多（正面凹、背面凸）；只熨一面更明显；边缘熔得比中心多；越大的图越容易翘；长条形最易弓起；根本原因是冷却时没有约束。〔新:果壳〕〔B站描述〕〔二〕
- 预防：烫完立刻压（压板比作品大）；整幅烫完再一次性压；双面烫；压到彻底冷。〔二〕〔英〕〔现〕
- 补救：复烫（背面朝上盖布轻扫 5–8 秒让它回软，立刻压平 15 分钟）；吹风机热风让它微软后重压；开水泡约 30 秒后夹出重压（视频自带不要随意模仿的提醒）。〔二:什么值得买 AIGC 摘要〕〔B站〕
- 例外：高温过熨导致的边缘卷曲压不平，因为材料已过度收缩。〔二〕

**D2 撕得太早 → 变形、拉丝** ★★
- 成因：热的时候豆子是软的，一撕就被扯变形；有人专门等降到不烫手再撕。〔现〕
- 反例：毛巾烫要趁热撕。〔现〕

**D3 正反面不平整 / 板钉凹痕** ★★
- 外观：背面有一圈圈凹陷（来自板钉）；正面是平的而背面有孔。
- 影响：磁片粘在凹凸面上接触面积小，容易掉。〔二〕
- 补救/预防：双面熨平背面；做冰箱贴的作品一定要双面熨。〔二〕

**D4 细结构断裂 / 磁铁掉 / 挂孔裂** ★
- 成因：一两格宽结构受热不足；穿孔位太靠边；磁片是小圆粒或位置偏离重心。〔二〕
- 预防：摆豆时就预留穿孔位且往内缩一格；片状磁贴 + 强力双面胶；大于 10cm 用两片。〔二〕

### E. 材料与环境

**E1 白豆变黄** ★★：EVA 在常温放久也会氧化发黄，受热更快；网上有黄脸 Hello Kitty 的翻车图；暂无好解法，可把发黄的白豆当黄豆用。〔新:果壳〕

**E2 熔点不同的豆混用** ★★：EVA 豆 80–110℃，融合豆（加 PE）130–170℃；同块混用会表面凹凸、局部过熔；但有玩家刻意用熔点不同的豆做肌理。〔新:果壳〕

**E3 高透豆 / 透明豆** ★：高透豆熔点较低、更软，静电与卡针更常见；有博主说普通透明豆烫后容易留气泡，而高透豆不会（单一来源）。〔现〕

**E4 珠光 / 荧光 / 夜光 / 半透明系列** ★：我只找到二手来源，称珠光涂层较薄、不当高温会磨掉闪粉；也有夜光豆挂件作品。没有第一手的熨烫行为描述，**这一条证据很弱**。〔二〕〔推〕

**E5 混豆 / 色差** ★：整包里混进了别的颜色或同色批次不同，导致熨后色差。〔现〕〔B站标题〕

**E6 劣质豆与气味** ☆：熨烫时刺鼻，可能含 ABS 或回收料；甲醛争议；店老板的做法：通风、买符合国标的豆、买甲醛仪自测。〔新〕〔现〕

### F. 人身与安全

**F1 熨斗烫伤 / 触电 / 起火** ☆（罕见但后果严重）
- 报道：央视曝光多款拼豆玩具附带的小熨斗直接接 220V 市电、无温控，通电 3 分钟底板可达 130℃ 以上；贵阳一名女孩 2026 年 3 月因使用违规熨斗触电身亡；山西运城有女孩被烫伤；河南有家庭监控显示熨斗突然爆炸起火，孩子手部烧伤。〔新〕〔B站标题〕
- 店里的态度：没经验的顾客不建议自己烫，由店员完成或指导。〔新:济南店〕

**F2 眼睛 / 颈腰 / 手抖** ★★
- 板面反光伤眼；单次时间过长近视增长（电视台视频标题：医生建议单次控制在 20 分钟以内）；腰酸背痛；手抖需手腕支点。〔现〕〔新〕

## 4. 体验与情绪：声音、触感、节奏、为什么解压

### 4.1 一次完整体验的「情绪曲线」
（我把多个来源拼成时间线；各阶段的具体描述见括号来源。）

| 阶段 | 身体在做什么 | 主观感受 | 来源 |
|---|---|---|---|
| 选图 | 翻图册/刷手机，比较难度 | 期待、犹豫；新手容易选太大 | 〔现〕〔二〕 |
| 取豆 | 在豆墙前一格一格取色，像自选餐 | 视觉上很「多巴胺」，有逛超市式的乐趣 | 〔新:上观、人人都是产品经理〕 |
| 摆豆 | 低头、手腕搭桌、小肌肉反复动作；半小时后开始放空 | 解压、治愈、可以放空；长时间后腰酸、眼累 | 〔新〕〔现〕 |
| 交烫 | 双手端板、屏息走到烫台 | 紧张（不可逆、怕撞翻） | 〔现〕 |
| 熨烫 | 点按—看—点按；翻面对光看孔 | 专注，且有一点害怕烫坏；烫成大图的店员会有点飘飘然 | 〔现〕 |
| 揭晓 | 撕烘焙布/澡巾、脱板 | 被比作拆盲盒，有人称是拼豆人最爽的时刻；撕澡巾的声音被说成特别解压 | 〔现〕 |
| 压平与收尾 | 压书、穿孔、拍照 | 成就感，想晒图 | 〔新〕〔现〕 |

**节奏特征**：很长的低强度、可重复的「累积期」（摆豆） + 很短的高风险、不可逆的「高潮期」（熨烫） + 一个明确的「揭晓」瞬间。〔推：综合以上〕

### 4.2 感官清单

**声音（线下店的真实声音是「很安静」）**
- 店内整体：像自习室；只有门铃声和偶尔低低的交谈（上观新闻对上海一家店的描写）；有博主说烫大图时边听小说边烫。〔新:上观〕〔现〕
- 摆豆：无声直播间里只有「哒哒」的细碎声响，几千人围观；用好豆子时「下豆声音清脆」；滑豆连发被形容像机关枪般的落豆声。〔新:头条〕〔现〕
- 豆子倒落/倒进盒子的「哗啦」声被剪成 ASMR（评论区常见强迫症被治愈的说法）；撕拼豆（脱模）有细腻的「沙沙」剥离声，B 站有纯原声 ASMR；「沉浸式收纳拼豆」（声控解压）单条抖音获 1666 万赞。〔现〕〔B站〕〔抖音标题〕
- 板与板的卡合：钉子卡进豆孔时「咔嗒」一声；〔现〕
- 熨斗：恒温器「咔嗒」切换、指示灯亮灭；到温时「叮」/「咔嘣」/烫画机「滴」；有人觉得熨斗一压就「吱呀」响；〔现〕
- 撕澡巾、撕烘焙布：被不少人认为特别解压；〔现〕

**触感**
- 豆：很轻、很小，带静电时会跳、会粘；2.6mm 豆几乎必须镊子或针；〔现〕
- 豆笔：松/紧有「手感」，要找到不松不紧的中间值；腕部有支撑才稳；〔现〕
- 豆板：钉子硬而细；板子反光；〔现〕
- 熨斗：热、有重量，新手要用「自重」；〔现〕
- 撕：热时软、撕不好变形；冷了变硬；毛巾烫要趁热撕；〔现〕
- 成品：好的融合豆烫出来的成品可以随意弯折，被当作质量标志；〔现〕

**视觉**
- 豆墙像一面彩虹；烘焙布下颜色变深、圆圈变方块；孔洞「透光」检查；融合后「通透」（高透豆）；〔现〕

**气味与温度**
- 熨斗和烘焙布的热；劣质豆的刺鼻；格利特布的气味大；PE 有淡淡树脂味、EVA 微酸（博主加热测试）；〔现〕

### 4.3 店里的氛围与人
- 客群：大学生、白领（有人带电脑一边拼一边工作、甚至开着会拼）、亲子（带娃做手工、减少电子屏幕）、情侣/闺蜜（同桌各做各的，不用找话题）、独自一人的「i 人」。〔新〕

### 4.4 为什么会觉得「解压」（来源给出的理由）
1. **确定性的成就感**：几小时内得到看得见摸得着的成果，对抗现实里的不确定与焦虑（新华社采访的上海社科院学者）。〔新〕

5. **反效率**：花三个小时拼一个歪歪扭扭的表情包，因为那是亲手做的；买的是一段只属于自己、不必有意义的时间。〔新:虎嗅〕
6. **社交货币与 ASMR**：晒图-点赞的反馈环；声音内容本身受欢迎。〔新〕
7. **代价**：低头弯腰的颈腰酸痛、眼睛疲劳、手抖；翻车时的崩溃。〔新〕〔现〕

## 5. 每个人的作品为什么不一样

### 5.1 人的选择（可控变量）

| 维度 | 具体差异 | 依据 |
|---|---|---|
| 图纸 / 审美 / IP | 动漫、偶像、表情包、经典艺术、电影、地毯纹样、植物；谁的包上挂什么，就能认出「同担」；圈内有「图纸老师」署名文化 | 〔新:虎嗅〕〔现〕 |
| 尺寸与板型 | 52/78/104 板或拼接大图；异形板；同一图可缩放 | 〔现〕 |
| 配色 | 色号替换（缺色用相近色，120 色足够）；刻意改色（有人把耳朵和眼睛换了颜色） | 〔现〕 |
| 工具与手法 | 镊子 / 单针 / 双针 / 滑豆；速度与出错率不同；有人手抖 | 〔现〕 |
| 摆放顺序 | 先轮廓 → 小色块 → 大面积；或逐行；影响出错位置 | 〔现〕〔二〕 |
| 烫法 | 有孔/无孔、单面/双面、毛巾/澡巾/格利特（粗/细闪）/仙度瑞拉/华夫格/空气炸锅纸/吸油纸/茶几垫 | 〔现〕〔二〕 |
| 成品形态 | 钥匙扣、冰箱贴、挂件、扇子、发夹、立体摆件、灯、旋转件、杯垫、相框 | 〔新〕〔现〕 |
| 个人二创 | 立体榫卯 3D 花灯、异形凹造型（回缩要预先多凹）、撒豆渐变 | 〔新〕〔现〕 |

### 5.2 物理上的随机性（不可控或难控变量）

| 来源 | 机制 | 结果 |
|---|---|---|
| 豆子公差 | 每批、每色的高度/直径/孔径/熔点有微小差异；便宜豆熨烫后表面发雾，品牌豆光滑有光泽（博主 200℃加热对比） | 同一图的表面起伏、孔洞大小、颜色深浅不同 |
| 静电 | 天气、新开袋、材质 | 豆乱跳、位置偏、连体 |
| 豆在钉上的状态 | 是否到底、是否倾斜、周围挤压 | 熨后连接强度与线条直度不同 |
| 热源 | 熨斗底板冷热不均（尖/中心 因机型而异）、烫画机板面、同一台机器不同位置 | 局部熔融程度不同、熨斗印 |
| 热沉 | 垫板（大理石/瓷砖/毛巾）的材质和当前温度；底下积热 | 闷豆概率、有孔面是否被烫化 |
| 手的动作 | 压力、停留时间、画圈/平移、换位置 | 晕色、线条歪、局部过熔 |
| 纸/布 | 褶皱、纹路错位、老化、毛絮 | 压痕、纹印、毛絮嵌入 |
| 环境 | 温度（二手说法：冬天要多烫 2–3 秒〔二〕）、湿度、气流 | 烫透程度、静电 |
| 冷却与压力 | 压板是否够大、压多久、是否双面 | 翘曲程度 |
| 撕的时机 | 热撕/冷撕、速度 | 变形、拉丝、毛粘附 |
| 人为失误 | 拼错、碰翻、手抖 | 局部返工或重来 |

**同图不同结果的一句话总结**：差异通常来自熨斗温度、助烫纸、冷却压平时间和豆子品牌（BeadsCanvas FAQ，二手）；英文教程反复强调需要靠试错找到自己熨斗的节奏。〔二〕〔英〕

### 5.3 对「赛博拼豆」模拟的含义（全部是我的推断〔推〕，不是调研事实）

真实过程里「会被玩家感知并讨论」的状态变量，可作为设计清单：
- **每颗豆**：色号；高度/直径/孔径的小公差（高低豆）；熔点（批次/颜色/品牌）；静电；在钉上的落座深度、倾斜或横躺；软化期可被推动的位置偏移；与邻居的「熔合键」；累计热量；是否粘到布/胶带上。
- **板**：钉高；平整度（被烫弯后豆处于不同高度）；一撞就散（未熨的豆只靠钉摩擦）。
- **工具**：镊子（夹飞、带倒邻豆）、豆针（卡针、静电吸附、一次 N 颗）、滑豆（要无毛刺豆 + 长钉 + 手随笔走）、豆铲/立豆盘（让豆立起来）。
- **热源与垫板**：熨斗底板热点（尖/前半段更烫，因机型而异）、恒温循环（灯亮灭）、烫画机的温度×时间×压力；垫板热容量和当前温度（积热 → 闷豆）。
- **纸/布**：皱纹、纹路、清洁度、正反面、老化。
- **冷却**：各豆收缩不均 → 翘曲；压平提供约束。
- **撕**：温度相关的粘附与变形；毛巾烫例外（趁热撕）。

值得复现的**反馈线索**：烘焙布下颜色变深、圆变方；背光检查孔洞；「咔嗒」（板卡合 / 恒温器）、「叮/滴」（到温）、「沙沙」（撕）、「哒哒」（落豆）、滑豆的连发音；手腕抖动；豆「哗啦」倒出。

**时间结构**：长而静的累积期 + 短而紧张的不可逆熨烫 + 揭晓瞬间 + 压平等待。许多「翻车」被社区做成笑料或可修复内容——可以设计成「有趣的失败」而不只是惩罚。

不建议仿真的内容：真实烫伤/触电细节、甲醛等健康风险（社区对此有争议，且我未做核实）。
