# 设计：把线下拼豆店搬进浏览器

这份文档回答两个问题：**线下店里发生的事，哪些被模拟了、在哪里实现；哪些没有做、为什么。**
所有事实和数值的出处在 `docs/research/`（流程与翻车图鉴：`offline-flow.md`；材料与物理：`materials-physics.md`；色卡：`palette-mard.json`）。

## 设计目标

1. **每个人的结果都不一样**——靠真实的变量（豆子公差和色差、毛发分布、熨烫的每一次停留和力度、撕纸的时机、你自己的摆法和错误），而不是随机数换皮。摆豆这一步是确定的、可预期的。
2. **操作和真实拼豆很像，每种材料都有物理质感**——尺寸、热模型、声音、材质都从调研数值出发。

## 流程对照

| 线下步骤（offline-flow §1） | 本项目 | 代码 |
|---|---|---|

| 2 取板 | 方 / 圆 / 心形板，小板 / 大板；透明板可看到下面的图纸 | `render/board.ts` |

| 7 备烫 | 垫大理石；选烫法（有孔 / 无孔）；选盖布（烘焙纸 / 烘焙布 / 澡巾）；选温度档 | `ui/stageIron.ts` |
| 9 熨烫 | 恒温熨斗（预热、叮、滞回控温、压在豆上会被抽走热量）；按压 / 抬起 / 换位置 / 转向；纸下的豆子变清晰就是「烫到位」的提示 | `render/iron.ts`、`interact/iron.ts`、`sim/melt.ts` |
| 10 对光检查 | 「掀一角看看」「热成像」（把热量画出来） | `render/paper.ts` |
| 11 降温撕布 | 要等豆子凉；纸边自己翘起；太早撕会拉变形、带走豆子、留纸屑 | `interact/iron.ts` |
| 12 压平 | 厚书 / 瓷砖 / 不压，压的时间越长越平 | `render/book.ts`、`interact/iron.ts` |
| 13 第二面 | 翻面，盖纸再烫一遍（更快） | `interact/iron.ts` |
| 14 后处理 | 钥匙扣：钻孔（可能裂）、开口环、珠链、摆动；相框 | `interact/finish.ts` |

## 材质与物理

- **拼豆**：中空短圆柱，2.6 mm（孔径 1.4 mm、壁厚 0.6 mm）或 5 mm；PE/EVA 缎面塑料，熔化后变光滑。受热量 `u` 控制：`0.25` 边缘开始融合（窗口感）→ `0.45–0.75` 孔洞缩到一半（最好看）→ `1` 孔闭合 → `>1.3` 过熔。圆 → 圆角方通过 superellipse 指数变形实现，所有变形都在顶点着色器里完成，阴影和 AO 通道共用同一份变形。
- **透明豆板**：不用折射（太贵），而是「极淡的底色薄雾 + 掠射角更不透明的钉壁 + 叠加的环境反射 + 钉子脚印贴花 + 板的软阴影」，在图纸之上依然清晰、在白纸上也看得出钉阵。
- **烘焙纸 / 布**：高度场跟着下面豆子的顶面（所以烫扁后会看到纸沉下去）、起皱 + 受热放平、豆子熔合处变清晰、可揭一角看、带毛发、盖布压痕。
- **熨斗**：浅薄荷色小旅行熨斗，拉丝不锈钢底板，圆润的两色塑料壳（由超椭圆截面沿长度放样），环形把手、旋钮和加热指示灯；恒温器带滞回，预热约 9 °C/s。
- **特殊豆**（`render/beadFinish.ts`）：果冻通透发亮；珠光随视角泛彩虹；夜光豆在「关灯」时发光；温变豆颜色随豆子温度翻转（约 31 °C）；光变豆发白、紫外灯下显色；闪粉豆会闪。成品页只在作品里有这类豆时才出现对应的开关。
- **光线**：窗光（带窗格投影的聚光灯 + 半球补光 + 程序环境贴图）；暗角 + S 曲线调色。

## 视觉与界面（`.impeccable.md`）

「晨光里的手作桌」：暖纸色界面、朱红强调色（OKLCH）、Fraunces + Noto Serif SC 做标题、Instrument Sans + Noto Sans SC 做正文；顶栏的步骤是一串豆子；色号圆片是一颗颗小豆的俯视图。窄屏（≤ 860 px）变成「画面在上、面板在下」的底部抽屉。

> **这份设计语境是我根据你的需求推断的，没有向你确认过**——受众（想动手 DIY 的普通人）、气质（温暖、手作、有一点幽默）、配色和字体都可以改，改的地方集中在 `src/ui/styles.css` 顶部的 token。
